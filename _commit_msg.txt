Windows 实时字幕 → DeepSeek 实时翻译

把 Windows 系统「实时字幕」的文本取出来，用 DeepSeek 翻译后显示在置顶浮窗上。
面向看英文视频的场景，重点是端到端延迟，以及一个能长期用的界面。

主要组成
- src/caption_reader.py   UI Automation 读取实时字幕（线程 COM 初始化、窗口重启自动重连）
- src/segmenter.py        把渐进式字幕流切成句子（稳定阈值 + 逗号从句 + 回溯改写去重）
- src/translator.py       DeepSeek 调用（流式、重试、模型退役兜底）
- src/app.py              采集 / 翻译 / 显示三线程 + 推测翻译 + 上下文
- src/overlay.py          置顶浮窗（仿 Windows 实时字幕外观，可拖动，圆角）
- src/settings_dialog.py  三页设置面板（21 项，外观类改动热应用）
- src/phrasebook.py       内置高频短语包（第一层，零延迟）
- src/cache.py            AI 学到的短句缓存（第二层）

提速上做过的实测取舍
- 推测翻译：定稿前先翻，实测命中率 86%，等于把断句等待藏起来
- 并发翻译：实测 API 响应在 0.9-4.6s 间波动，单线程会让滞后持续累积
- 逗号从句：长句不再等整句说完，真实日志实测提前 3 秒
- 分页与缓存热应用：改外观不用重启

遇到并修掉的坑（都记在 README 的「真实数据实测发现」里）
- 实时字幕会把 one 改写为 1、把句号改成逗号，导致同一句被翻译两遍
- 转录是滚动窗口，翻页时未定稿的残句会被静默丢弃（实测丢过 14% 的内容）
- 去重曾在字符串层面比较，导致 A. 会把 All of the... 整句吞掉

测试：257 项单元测试 + 92 项端到端（含真实服务与真实实时字幕）
